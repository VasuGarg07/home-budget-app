# Home Budget

Offline income and expense tracker for Android. See `DESIGN.md` for the design and rules.

## Preview on your PC
```
npm install
npm run dev
```
Open the address it prints in a browser and use the phone-size view.

## Get the app on your phone
1. Push this repo to GitHub (branch `main`).
2. Open the Actions tab and wait for "Build APK" to finish.
3. On your phone, open the repo's Releases page, download `home-budget.apk` from "Latest build", and install it (allow installs from unknown sources when asked).
